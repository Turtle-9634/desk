# 知予工作台

手机和电脑都能打开的个人工作台：主持档期、PR 待办、账号更新、收入记账、周复盘。

数据不经过任何第三方服务器，直接存在你自己的 GitHub 私有仓库里。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 全部界面和逻辑，单文件，无依赖 |
| `manifest.json` | 添加到主屏幕时的名称、图标、全屏设置 |
| `icon-180.png` `icon-192.png` `icon-512.png` | 主屏幕图标 |
| `sw.js` | 断网时也能打开页面 |

## 第一次使用

1. 用手机或电脑打开本页网址
2. 进入「账号 → 设置与同步」，填入 GitHub 令牌
3. 手机浏览器「分享 → 添加到主屏幕」，以后点开就是全屏

## 关于数据

- 页面本身不含任何数据，别人打开看到的是空的工作台
- 数据存在私有仓库的 `data.json`，只有拿着令牌的人能读写
- 每次保存相当于一次提交，改错了可以从提交历史里翻回任意一天
- 手机和电脑改同一个字段时，以最后一次修改为准；改不同字段时两边都保留

## 更新页面

改完 `index.html` 上传到本仓库即可。GitHub Pages 有约 10 分钟缓存，页面右下角的版本号会跟着变。
